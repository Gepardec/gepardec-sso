# gepardec-sso
Repository contains all customizations of the Gepardec Keycloak

# Local Keycloak Setup

**Build Image**
```shell
podman build -t gepardec-sso:local .
```

**Create Network**
```shell
podman network create gepardec-sso
```


**Run DB:**
```shell
podman run -d --name gepardec-sso-postgres --network=gepardec-sso -e POSTGRES_DB=keycloak -e POSTGRES_PASSWORD=keycloak@123 -e POSTGRES_USER=keycloak -p 5432:5432 postgres:15
```


**Run Keycloak:**
```shell
podman run -e KC_DB_PASSWORD=keycloak@123 \
           -e KC_DB_URL=jdbc:postgresql://gepardec-sso-postgres:5432/keycloak \
           -e KC_DB_USERNAME=keycloak \
           -e KC_HOSTNAME_ADMIN=http://localhost:8080 \
           -e KC_HOSTNAME=http://localhost:8080 \
           -e KC_HTTP_ENABLED=true \
           -e KC_HTTPS_PORT=8080 \
           -e KEYCLOAK_ADMIN=admin \
           -e KEYCLOAK_ADMIN_PASSWORD=admin@123 \
           --network=gepardec-sso \
           -p 8080:8080 -p 9000:9000 \
           --name gepardec-sso \
           --rm \
           localhost/gepardec-sso:local \
           start --optimized --verbose
```

**Keycloak mit keycloak-config-cli konfigurieren:**
```shell
cd ../gepardec-sso-config-ci/ && podman run --rm --name gepardec-sso-config-cli --network=gepardec-sso -e KEYCLOAK_URL="http://gepardec-sso:8080/" -e KEYCLOAK_USER="admin" -e KEYCLOAK_PASSWORD=admin@123 -e KEYCLOAK_AVAILABILITYCHECK_ENABLED=true -e IMPORT_MANAGED_CLIENT=no-delete -e KEYCLOAK_AVAILABILITYCHECK_TIMEOUT=120s -e IMPORT_FILES_LOCATIONS='/config/*' -v ./apps/appuio/qa/configs:/config quay.io/adorsys/keycloak-config-cli:6.5.1-26.5.5
```

# Keycloakify Login Theme

The Gepardec login theme lives in [`theme/`](theme/) and is built with [Keycloakify](https://keycloakify.dev) v11: a React + TypeScript + Vite project that is compiled into a regular Keycloak theme JAR (`gepardec-login-theme.jar`, theme name `gepardec`). It only customises the **login** theme; account, admin and email themes are not implemented.

## Layout

| Path (under `theme/`) | Purpose |
|---|---|
| `src/login/KcPage.tsx` | Entry point per page. Renders every page via Keycloakify's `DefaultPage` and maps hook classes (`kcLoginClass`, ...) to Gepardec classes. Add a `switch (kcContext.pageId)` here only when ejecting a page. |
| `src/login/main.css` | All styling: brand tokens (`--gc-*`), font, background, card, buttons, alerts, responsive rules. |
| `src/login/i18n.ts` | Custom English/German translations (`withCustomTranslations`). Only override keys that differ from Keycloak's defaults. |
| `src/login/assets/img/` | Logo, background image and favicon. Import via relative paths so Vite hashes them; do not put them in `public/`. |
| `src/login/KcContext.ts` | Typed `kcContext` (extend here if a template needs extra Keycloak variables). |
| `src/login/KcPageStory.tsx`, `src/login/pages/*.stories.tsx` | Storybook helpers and stories per Keycloak page. |
| `src/main.tsx`, `index.html`, `vite.config.ts` | Dev/build entry points and Keycloakify plugin config (theme name, target JAR). |
| `src/kc.gen.tsx`, `public/keycloakify-dev-resources/` | **Generated by Keycloakify, do not edit** (the latter is git-ignored). |

## Commands

Run from the repository root (or `cd theme` and drop `--prefix theme`):

```shell
npm --prefix theme ci                          # install dependencies
npm --prefix theme run storybook               # preview pages at http://localhost:6006
npm --prefix theme run build                   # typecheck + Vite bundle
npm --prefix theme run lint                    # ESLint
npm --prefix theme run format:check            # Prettier check (use `format` to fix)
npm --prefix theme run build-keycloak-theme    # build theme/dist_keycloak/gepardec-login-theme.jar (needs Maven + Java)
npx --prefix theme keycloakify start-keycloak -p theme   # test in a local Keycloak container
npx --prefix theme keycloakify add-story -p theme        # add a Storybook story for a page
```

## How it reaches Keycloak

The `Containerfile` builds the theme in a Node stage (`npm ci` + `npm run build-keycloak-theme`) and copies `dist_keycloak/gepardec-login-theme.jar` into `/opt/keycloak/providers/` before `kc.sh build`. Select the theme in the realm under *Realm settings > Themes > Login theme: gepardec*.

## Customising

Prefer the least invasive option, in this order:

1. **CSS** in `main.css`, targeting Keycloakify's stable `.kc*` hook classes or the `classes` map in `KcPage.tsx`.
2. **Translations** in `i18n.ts`.
3. **Eject a page** only if the HTML structure must change: `npx --prefix theme keycloakify eject-page -p theme`. Ejected pages must be justified, since they must be kept in sync on Keycloakify upgrades.

Add or update a Storybook story for every login page you change. Never commit `theme/dist_keycloak/` or `theme/public/keycloakify-dev-resources/`.
